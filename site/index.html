우리 일정

컴퓨터와 휴대폰에서 쓰는 일정 겹쳐보기 앱. 최대 5명이 각자의 주간 일정을 겹쳐 보고, 모두 비어 있는 시간을 한눈에 찾아요.

웹에서 바로 쓰기

설치 없이 컴퓨터·휴대폰 어디서나. 함께 쓰기(실시간 방)도 그대로 돼요.

우리 일정 열기
  1. 휴대폰(안드로이드) — Chrome으로 열고 오른쪽 위 ⋮ → 홈 화면에 추가(또는 앱 설치)를 눌러요.
  2. 아이폰·아이패드 — Safari로 열고 아래 공유 버튼 → 홈 화면에 추가를 눌러요.
  3. 컴퓨터 — Chrome이나 Edge로 열고 주소창 오른쪽의 설치 아이콘을 누르면 앱처럼 따로 창이 떠요. 앱 아래 "앱으로 설치" 버튼으로도 돼요.
홈 화면에 추가하면 아이콘을 눌러 앱처럼 열고, 인터넷이 없을 때도 열려요. 카카오톡 안에서 열었다면 오른쪽 위 메뉴의 "다른 브라우저로 열기"를 눌러 주세요. 휴대폰과 컴퓨터를 같이 쓰면 "함께 쓰기 → 내 다른 기기 연결"로 같은 사람으로 묶을 수 있어요.

Windows 앱

Windows 10, 11

설치 파일 내려받기
  1. 내려받은 uri-iljeong-setup.exe를 두 번 눌러 실행해요.
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 눌러요. (개인이 만든 앱이라 처음엔 이 안내가 떠요.)
  3. 바탕화면과 시작 메뉴에 생긴 우리 일정을 열면 끝이에요.
새 버전이 나오면 앱이 알아서 내려받아 두었다가, 다음에 켤 때 바뀌어요.

안드로이드 앱 (APK)

Android 7 이상

APK 내려받기
  1. 휴대폰의 Chrome에서 이 페이지를 열고 APK 내려받기를 눌러요.
  2. 다 받아지면 알림이나 "내 파일 → 다운로드"에서 uri-iljeong.apk를 눌러요.
  3. "출처를 알 수 없는 앱" 안내가 뜨면 설정 → 이 출처 허용을 켜고 돌아와 설치를 눌러요.
  4. "Play 프로텍트" 안내가 뜨면 무시하고 설치(또는 세부정보 → 설치)를 눌러요.
새 버전은 이 페이지에서 다시 내려받아 설치하면 일정은 그대로 두고 앱만 바뀌어요.
