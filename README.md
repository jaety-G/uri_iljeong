# 우리 일정

여러 명이 각자의 주간 일정을 겹쳐 보고, 모두 비어 있는 시간을 한눈에 찾는 앱이에요. 사람 수 제한은 없어요.

## 쓰는 법 한눈에

- **칠하기**: "나는"에서 내 이름을 고르고 칸을 눌러요. 컴퓨터는 끌어서 여러 칸, 휴대폰은 **톡 = 한 칸, 길게 누른 채 끌기 = 여러 칸**(그냥 밀면 화면이 움직여요).
- **월간**: 컴퓨터는 날짜마다 "10–12 전공 수업"처럼 보여요. 휴대폰은 날짜에 색 점(일정 있는 사람)만 보이고, 날짜를 누르면 아래에 그날 일정과 모두 빈 시간이 크게 나와요.
- **메뉴바**: 휴대폰에서 화면 왼쪽 끝을 오른쪽으로 밀면 열리고, 왼쪽으로 밀면 닫혀요.
- **달력 색**: 토요일은 파랑, 일요일·공휴일(대체·임시공휴일 포함, 2024~2027 공공데이터 기준)은 빨강, 오늘은 검은 동그라미예요.
- **시작 화면**: 웹 버전을 로그인하지 않고 열면 "구글로 시작하기 / 로그인 없이 쓸게요" 화면이 잠깐 떠요. 로그인 없이를 누르면 그 창(탭)을 닫을 때까지 다시 안 떠요.

- **아이폰·웹 버전**: 다운로드 페이지의 "웹 버전 열기"를 홈 화면에 추가해서 써요.
  (아이폰 설치 파일은 유료 애플 개발자 계정이 있어야 만들 수 있어요.)

## 폴더 구성

| 경로 | 하는 일 |
|---|---|
| `app/` | 앱 화면 전체 (Windows 앱과 웹 버전이 같이 써요) |
| `main.js` | Windows 앱 창 띄우기, 자동 업데이트 |
| `android/` | 안드로이드 앱 프로젝트 (Capacitor). 화면은 `app/`을 그대로 써요 |
| `capacitor.config.json` | 안드로이드 앱 이름·설정 |
| `build/` | 앱 아이콘 |
| `site/index.html` | 다운로드 페이지 |
| `firestore.rules` | 함께 쓰기 저장소(Firebase) 규칙 |
| `.github/workflows/release.yml` | 태그를 올리면 Windows·안드로이드 설치 파일을 만들어 Releases에 올림 |
| `.github/workflows/pages.yml` | 다운로드 페이지와 웹 버전을 GitHub Pages에 올림 |

## 처음 한 번만 하는 설정

1. GitHub에서 **새 저장소**를 만들어요 (예: `uri-iljeong`, Public).
   - Private 저장소는 친구들이 설치 파일을 내려받을 수 없고, 자동 업데이트도 안 돼요.
2. 이 폴더의 파일을 모두 저장소에 올려요. (`.github` 폴더도 꼭 같이)
   - 웹에서 올릴 때: 저장소 첫 화면의 **uploading an existing file** → 폴더 안 파일을 모두 끌어다 놓기 → **Commit changes**.
     `.github` 폴더가 빠지면 자동 빌드가 안 되니, 올린 뒤 저장소에 `.github/workflows` 가 보이는지 확인해 주세요.
3. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔요.
4. 저장소 **Settings → Actions → General → Workflow permissions**가 **Read and write permissions**인지 확인해요.
5. **안드로이드 서명 키**: `E:\OurPlan\android-signing\README-서명키.txt`를 열고, 적힌 대로
   저장소 **Settings → Secrets and variables → Actions → New repository secret**에서 4개를 만들어요.
   - 서명 키 폴더는 절대 저장소에 올리지 말고, 따로 백업해 두세요. 잃어버리면 안드로이드 앱을 업데이트할 수 없어요.

## 새 버전 내보내기

1. 저장소 오른쪽의 **Releases → Draft a new release**를 눌러요. (처음이면 **Create a new release**)
2. **Choose a tag**에 `v1.0.0`처럼 새 번호를 적고 **Create new tag**를 눌러요.
3. **Publish release**를 누르면 몇 분 뒤 `uri-iljeong-setup.exe`(Windows)와 `uri-iljeong.apk`(안드로이드)가 그 릴리스에 붙어요.
   - 진행 상황은 **Actions** 탭에서 볼 수 있어요.
   - 다음 버전은 `v1.0.1`, `v1.1.0`처럼 번호를 올려 주세요. 이미 설치한 사람들 앱이 자동으로 바뀌어요.

## 사람 색 바꾸기

- 사람 관리 창(+ 버튼 또는 이름 칩 두 번 누르기)에서 이름 옆 **색 동그라미**를 누르면 파스텔 12가지와 **직접 고르기**가 나와요.
- 칩 테두리용 진한 색은 자동으로 맞춰져요. 다른 사람이 쓰는 색에는 작은 점이 붙어요.
- 함께 쓰는 방에서 직접 고른 색을 쓰려면 `firestore.rules`의 최신 내용이 Firebase 규칙에 게시되어 있어야 해요.

## 일정표 여러 개 (왼쪽 메뉴바)

- 왼쪽 메뉴바의 **새로 만들기**로 일정표를 여러 개 만들 수 있어요. (예: 동아리, 팀플, 가족)
- 일정표마다 사람·일정·보기 설정(주간/월간, 시간대)·함께 쓰는 방이 따로예요.
- 이름은 위쪽 제목을 누르거나, 목록의 `⋯` → 이름 바꾸기로 바꿔요. `⋯` → 삭제로 지울 수 있어요.
- `⋯` → **메인으로 지정**: 앱을 열면 이 일정표가 먼저 보여요(하나만). `⋯` → **맨 위에 고정**: 목록 맨 위 "고정됨"에 모여요(여러 개).
- 일정표 목록은 기기마다 따로 저장돼요. 다른 기기에서도 같은 일정표를 보려면 그 일정표로 방을 만들어 함께 쓰기를 해 주세요.
- 휴대폰에서는 왼쪽 위 버튼으로 메뉴바를 열어요.

## 루틴 시간표 (날짜 없음)

- 위쪽 주간/월간/기간 옆의 **루틴 시간표**를 켜면 그 일정표가 날짜 없는 루틴 시간표로 바뀌어요. (일정표마다 따로 켜고 꺼요)
- **주간 = 매주 루틴**: 날짜 없이 월~일만 있는 표예요. 학교 시간표처럼 칠해 두세요.
- **월간 = 매달 루틴**: 1~5주차 × 요일 표예요. "매달 2주차 토요일 회의" 같은 걸 넣어요. 주차를 누르면 그 주차 표로 들어가 칠해요.
- 날짜 달력에 칠해 둔 주가 있으면 **보던 주를 루틴으로 가져오기**로 한 번에 옮길 수 있어요.
- 루틴과 날짜 일정은 따로 저장돼요. 루틴 시간표를 끄면 날짜 달력이 그대로 있어요.

## 아이디 로그인

- 왼쪽 메뉴 아래(또는 시작 화면) **로그인 · 아이디 만들기**에서 원하는 아이디(영문 소문자·숫자 3~20글자)와 비밀번호(6글자 이상)를 정해요.
- 다른 기기(휴대폰·다른 컴퓨터, 홈 화면 앱 포함)에서 같은 아이디로 로그인하면 일정표 목록과 일정이 그대로 보이고, 실시간으로 맞춰져요.
  그 기기에만 있던 일정표는 계정에 합쳐지고, 함께 쓰는 방에 그 기기가 따로 들어가 있었으면 하나로 합쳐져요.
- 비밀번호를 잊으면 찾을 수 없어요. 꼭 기억해 두세요. 로그인한 뒤 메뉴의 **비밀번호 바꾸기**로 바꿀 수 있어요.
- 예전에 구글로 로그인해 둔 기기는 메뉴의 **아이디 만들기**로 지금 일정 그대로 아이디를 만들 수 있어요.
- 로그아웃하면 내 일정표는 이 기기에 사본으로 남고, 함께 쓰는 방은 다시 로그인하면 돌아와요.
- 처음 한 번(Firebase 콘솔): **Authentication → 로그인 방법 → 이메일/비밀번호** 켜기, 최신 `firestore.rules` 게시.
  (아이디는 Firebase에 `아이디@id.uri-iljeong.app` 형태로 저장돼요. 진짜 메일 주소가 아니에요.)

## 함께 쓰기 (실시간 방)

같은 "방"에 들어온 사람끼리 일정이 실시간으로 맞춰져요. 구글의 무료 저장 서비스 Firebase를 써요.

- 처음 한 번(Firebase 콘솔):
  1. **Authentication → 로그인 방법 → 익명**을 켜요. (기기마다 자동으로 붙는 이름 없는 로그인이에요)
  2. **Firestore Database → 규칙**에 `firestore.rules` 내용을 붙여 넣고 게시해요.
- **새 방 만들기**: 방 이름과 내 이름을 적으면 새 일정표로 방이 생기고, 나는 **1번(방장)**이에요.
  "나는"으로 골라 둔 사람의 일정이 내 일정으로 같이 올라가요. 지금 일정표는 그대로 남아요.
- **방 코드로 들어가기**: 방 이름 그대로 새 일정표가 생기고, 나는 다음 번호(**2번, 3번…**)가 돼요. 인원 제한은 없어요.
- 번호는 서버가 한 자리씩만 내줘서, 여러 명이 동시에 들어와도 같은 번호가 생기지 않아요.
- 각자 **자기 이름·색·일정만** 바꿀 수 있어요(서버 규칙으로도 막혀 있어요). 방 이름은 방장만 바꿀 수 있어요.
- **내 다른 기기 연결**: 휴대폰과 컴퓨터를 같이 쓰면, 한 기기의 "함께 쓰기 → 연결 코드 만들기"로 20글자 코드를 만들고
  다른 기기의 "함께 쓰기"에 넣어요(10분 안에). 두 기기가 같은 사람이 되고, 그 기기에서 따로 쓰던 내 일정은 합쳐져요.
  기기를 하나 더 연결해 두면 앱을 지웠다 다시 깔아도 이어서 쓸 수 있어요.
- **방 나가기**: 방에서 내 자리와 내 일정이 지워져 다른 사람이 들어올 수 있어요. 보던 일정은 이 기기에 복사돼요.
  방장이 나가면 다음 번호 사람이 방장이 돼요. 연결한 기기에서 나가면 그 기기만 빠져요.
- 방 코드를 아는 사람은 누구나 방을 볼 수 있으니, 코드는 함께 쓸 사람에게만 보내 주세요.
- 인터넷이 끊기면 그동안은 보기만 할 수 있고, 다시 연결되면 이어서 쓸 수 있어요.
- 같은 기기의 앱 데이터를 지우면 그 기기는 새 사람으로 들어가요. 미리 다른 기기를 연결해 두면 그 기기에서 코드를 만들어 다시 연결할 수 있어요.
- 2026년 11월 11일 전에 만든 방은 예전 방식이라 고칠 수 없어요. 새로 만들어 주세요.

## 친구와 일정 맞추기 (방 없이)

방을 만들지 않으면 일정은 각 기기에 저장돼요. 앱 아래 **코드로 한 번 보내기**(웹: 링크로 한 번 보내기)로 코드를 복사해 카카오톡으로 보내고,
받은 사람은 **받은 코드 붙여넣기**에 넣으면 일정이 합쳐져요. 같은 사람의 일정은 더 최근에 고친 쪽으로 맞춰져요.
처음에는 한 명이 사람을 모두 추가해서 코드로 나눠 주세요.

## 알아 둘 점

- 코드 서명을 하지 않은 앱이라, 처음 설치할 때 "Windows의 PC 보호" 창이 떠요. **추가 정보 → 실행**을 누르면 돼요.
  이 안내를 없애려면 유료 코드 서명 인증서가 필요해요.
- Windows 앱은 삭제해도 일정이 남아요. 안드로이드 앱은 **삭제하면 일정도 지워지니**, 지우기 전에 "받은 코드 붙여넣기 · 백업"에서 전체 백업을 복사해 두세요. (새 버전을 덮어 설치하는 건 괜찮아요.)
- 새 버전이 나오면 Windows 앱은 스스로 받아 두었다가 다음에 켤 때 바뀌어요. 안드로이드 앱은 위쪽에 "새 버전이 나왔어요" 안내가 떠요.
- 안드로이드는 Play 스토어 앱이 아니라서 설치할 때 "출처를 알 수 없는 앱 허용"과 "Play 프로텍트" 안내가 떠요. 다운로드 페이지에 누를 곳을 적어 두었어요.

## 직접 빌드하기 (개발용)

```
npm install
npm start        # 앱 실행
npm run dist     # dist/ 에 설치 파일 만들기 (Windows에서)
npm run android:sync   # app/ 을 고친 뒤 안드로이드 프로젝트에 반영 (Android Studio로 열어 실행)
```
